# Прогнозирование оформления срочного вклада клиентом банка

Проект по машинному обучению: по данным телефонных маркетинговых кампаний португальского банка предсказываем, оформит ли клиент срочный вклад.

## О проекте

- **Задача:** бинарная классификация (`y` = yes / no).
- **Данные:** [Bank Marketing]([https://archive.ics.uci.edu/dataset/222/bank+marketing]), файл `bank.csv` (45 211 записей, 16 признаков).
- **Практический смысл:** ранжировать клиентов по вероятности согласия, чтобы тратить меньше звонков на тех, кто вряд ли согласится.
- **Особенности:** дисбаланс классов (около 12% «yes»); признак `duration` исключён как утечка данных (известен только после звонка).
- **Главная метрика:** recall по классу «yes» (пропущенный клиент обходится дороже лишнего звонка), дополнительно ROC-AUC, precision, F1.

## Что сделано

1. Разведочный анализ данных (EDA).
2. Предобработка: новые признаки, лог-преобразование, масштабирование, кодирование категорий.
3. Базовая модель: LogisticRegression.
4. CatBoost с подбором гиперпараметров (Optuna).
5. Нейросеть (Keras) с подбором гиперпараметров (Optuna).
6. Сравнение моделей, анализ важности признаков, выводы.

## Результаты (тестовая выборка, порог 0,5)

| Модель | Recall | Precision | F1 | ROC-AUC |
|---|---|---|---|---|
| LogisticRegression | 0,668 | 0,268 | 0,383 | 0,780 |
| CatBoost | 0,642 | 0,306 | 0,414 | 0,791 |
| Keras (MLP) | 0,662 | 0,306 | 0,418 | 0,796 |

Нейросеть и CatBoost показывают сопоставимое качество и заметно лучше линейной модели. Нейросеть охватывает около 66% заинтересованных клиентов, обзванивая около четверти базы. В обеих моделях наиболее важны признаки `contact` и `month`.
